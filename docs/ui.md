# UI Layout & Display Standards

## 1. 路徑與顯示規範 (Path & Display Standards)
- **統一分隔符**: 專案內所有 UI 顯示、日誌輸出以及資源包內部的相對路徑，**一律強制轉換為 `/` (Unix Style)**。嚴禁在 Windows 環境下輸出混合 `\` 的路徑。
- **路徑提取**: 透過 `utils::extract_display_path` 進行智慧縮減，僅顯示 `modid/en_us.json` 等關鍵資訊。

## 2. UI 佈局與視窗規範 (UI Layout & Window Specs)
- **主視窗設計**:
  - 版面分為三大區塊：**頂部（設定與控制面板）**、**中部（進度條區與翻譯狀態）**、**底部（日誌區域）**。
  - **按鈕規格 (關鍵)**:
    - 「開始翻譯」固定尺寸為 `120.0 x 32.0`。
    - 「暫停/停止/繼續」固定尺寸為 `80.0 x 32.0`。
  - **色彩與屬性規範 (Revision 15.20)**:
    - **常量管理**: 所有標籤顏色必須引用 `LABEL_COLOR_LIGHT` 與 `LABEL_COLOR_DARK` 常量，禁止硬編碼。
    - **淺色模式標籤**: 採用 **深靛藍色 (#1E3C78)** 以對抗淺橘色背景。
    - **深色模式標籤**: 採用 **淺沙色 (#C8A064)**。
    - **屬性**: 標籤一律套用 `.strong()` (粗體)，並移除斜體與小字裝飾。
  - **佈局對齊與防遮擋**:
    - 頂部導航鈕（⚙, 🌓, 📖, 🔧）必須固定置右排列。
    - 輸出路徑標籤獨立分行，並強制使用 `truncate(true)` 防止與按鈕重疊。
- **Viewport 穩定性**:
  - **閃爍修復**: 針對 `egui` Viewport 開啟時的繪製衝突，實作了 `opened_last_frame` 旗標與延遲渲染機制，確保建議詞管理器開啟時不產生畫面跳位或閃爍。
- **UI 鎖定機制 (Revision 11.2 細粒度控制)**:
  - 翻譯進行中 (`processing == true`) 時，**僅鎖定核心 API 參數**:
    - 鎖定：服務商選單、恢復預設、模型選單、金鑰/URL、批次量、字數上限、逾時、翻譯提示。
  - **始終保持開啟**: 🌓 主題切換、📖 建議詞管理器、⚙ API 設定面板開關、**🔄 刷新模型按鈕**、**字體大小調整**。
- **數值交互 (DragValue UX)**:
  - 所有 `DragValue` 組件必須配置適當的 `speed` 參數。
  - 支援 **滑鼠滾輪** 與 **鍵盤上下鍵** 直覺式微調，不要求必須點擊拖曳。

## 3. 建議詞管理器 (Glossary Manager)
- **獨立視窗**: 具備雙分頁設計（使用者/官方）。
- **視覺基準**: 表格欄位原文與翻譯強制與背景帶狀條紋對齊，支援長文本自動換行。表格右側操作按鈕 (✏/🗑) 必須與文字行中線對準。
- **時機同步**: 點擊 📖 按鈕時即時觸發 `is_memory_viewer_open` 的原子同步。

## 4. Log 日誌管理
- 採用 `egui::ScrollArea::show_rows` 並強化 monospace 渲染風格。
- 畫面 Log 不設渲染上限，僅過濾瑣碎掃描輸出，確保「零警告」與「高效能」並存。
