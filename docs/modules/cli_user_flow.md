# CLI 運作流程

CLI 提供兩種模式: headless 參數模式與互動式導覽。

## Headless 參數模式

- 當使用 `-i/--input` 時即進入 headless 模式
- 以參數覆蓋設定檔值
- 直接啟動翻譯流程

## 互動式導覽流程

步驟概覽:

1. 選擇介面語言
2. 選擇 API 服務商
3. 輸入 API Key (Ollama 與 Google Free 會跳過)
4. 選擇模型 (支援動態拉取或自訂輸入)
5. 選擇輸入路徑
6. 選擇輸出資料夾
7. 確認與開始

## 重要行為

- 介面語言會即時寫入 `settings/config.cfg`（因為需要重新載入 i18n 檔案）
- Step 2-6 的設定**不會即時儲存**，而是在 Step 7 確認後統一寫入
- 取消可回到前一步
- 翻譯完成後可選擇進行新任務
