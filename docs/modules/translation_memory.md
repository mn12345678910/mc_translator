# 翻譯記憶體與緩存 (.cache)

## 1. 持久化邏輯
翻譯記憶體（Translation Memory）負責記錄已成功翻譯的對應關係。

### 檔案結構 (.cache / user.json)
- **Key**: 原始英文字串（經過標準化處理）。
- **Value**: 翻譯後的繁體中文字串及元數據。

## 2. 緩存機制
- **啟動加載**: 程式啟動時會將 `dicts/*.json` 全部加載至內存硬雜湊表 (HashMap)。
- **即時提交**: 每當一批次翻譯完成，系統會非同步將增量內容寫入磁碟，防止異常中斷導致進度丟失。

## 3. 併發讀寫保護
- 使用 `Arc<dashmap::DashMap>` 或具備讀寫鎖 (RwLock) 的容器，確保多個翻譯執行緒同時查詢記憶體時的執行緒安全。
