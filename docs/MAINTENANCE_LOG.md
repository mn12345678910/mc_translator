## [2026-03-10] Revision 15.1 - Git 版本控制與文檔同步
- **Git 初始化**: 啟動了 Git 倉庫，建立了 `.gitignore`，並完成了首次提交 (Initial commit)。
- **文檔索引更新**: 更新 `AI_CONTEXT.md` 以記錄 `docs/` 目錄下所有文件的角色與內容。


## [2026-03-10] Revision 14.6 - 遷移邏輯與 UI 文字優化
- **官方詞條自動遷移**: 實作了「修改即移入」邏輯。現在對「官方建議詞」分頁進行編輯或批量取代後，受影響的條目將自動寫入使用者字典 (`user.json`) 並從官方字典 (`official.json`) 中移除，實現個人化設定的隔離。
- **取代對話框文字精製**: 將批量取代對話框的輸入欄位標籤從「尋找目標/取代為」更新為更直覺的「原Value:」與「新Value:」。
- **知識庫同步**: 更新 `AI_CONTEXT.md`，將遷移行為與鍵盤交互規範納入 AI 接手指引。


## [2026-03-10] Revision 14.5 - 核心邏輯修補與 UI 精製
- **取代功能徹底修復**: 解決了在雙分頁執行取代時 UI 未能即時反應的問題。現在取代後會同步更新內存地圖 (`inferred_match_map`) 並顯式請求重繪，確保變更立即顯現且檔案持久化可靠。
- **按鈕順序最優化**: 針對單筆編輯模式，將「存檔 (💾)」與「取消 (❌)」順序對調。在 `right_to_left` 佈局下，現在存檔按鈕會穩定出現在最右側，與編輯/刪除按鈕的操作習慣保持高度一致。
- **編譯環境清理**: 移除了所有未使用的變數說明（如 `term_replacements`）與不必要的 `mut` 聲明。目前 `cargo check` 狀態為完全乾淨（零警告、零錯誤）。


## [2026-03-10] Revision 14.4 - 功能修正與鍵盤化優化
- **取代功能修復**: 修正了取代按鈕在使用者與官方分頁失效的問題，並實施了「精確匹配」判斷。官方分頁的取代結果現在會正確同步至 `user.json`。
- **鍵盤快捷支援**: 為「新增」、「取代」對話框以及表格「單筆編輯」模式新增 Enter 鍵支援。按下 Enter 鍵即可快速執行確認或存檔，顯著提升操作效率。
- **對話框定位解鎖**: 移除新增與取代對話框的強制中央錨點。對話框現在可以自由移動與調整位置，不再遮擋背景資訊。
- **按鈕順序優化**: 調整了 `right_to_left` 佈局中的按鈕順序。現在「🗑」（刪除）與「💾」（保存）會固定出現在每組操作的最右側，優化 UI 直覺性。


## [2026-03-10] Revision 14.3 - 表格佈局精製與按鈕對齊優化
- **表格列對位修復**: 將標題與內容欄位由自動撐開的垂直置中佈局改為固定寬度的置中 Label，徹底解決第一欄（Key）過度擴張導致後續欄位（Value、操作）被擠出視窗的問題。
- **操作按鈕置右**: 將表格每行的「編輯」與「刪除」按鈕改為靠右對齊排列，符合標準 UI 操作邏輯。
- **同步機制健全化**: 強化了切換主題時的 `request_repaint` 循環，確保建議詞視窗在主畫面變動時能即時重新渲染，不論視窗是否處於聚焦狀態。


## [2026-03-10] Revision 14.2 - 佈局穩定性與同步強化
- **視窗放大修復**: 禁用 `ScrollArea` 的水平捲動，鎖定內部的 `Grid` 遵循視窗寬度，解決了表格內容長度導致視窗無限橫向增長的佈局遞迴問題。
- **無縫主題同步**: 在主介面切換主題或字型時，新增對建議詞管理器視窗的顯式 `request_repaint` 請求。現在即使子視窗未聚焦，也能與主視窗同步變更。


## [2026-03-10] Revision 14.1 - 建議詞管理器功能修復與 UI 強化
- **全面功能修補**: 修復了導致建議詞視窗在開啟時發生語法錯誤或閃退的代碼回歸，恢復 Add/Replace 對話框 (Window) 的顯示。
- **CRUD 邏輯校正**:
    - **編輯同步**: 針對「官方分頁」條目的編輯內容，現在會正確同步存入使用者字典 (`user.json`)，落實自定義優先邏輯。
    - **精確刪除**: 修復了刪除 (🗑) 按鈕，確保根據目前所處分頁（使用者/官方）正確刪除對應字典條目並即時存檔。
- **雙開功能增強**: ".json" 按鈕現在實作雙重功能：同步以「預設編輯器」開啟對應 JSON 檔案，病同時以「檔案總管」開啟所在資料夾且自動選中該檔案。
- **UI 佈局優化**:
    - **標題置中**: 表格標題更新為 "Key / Value" 並實施垂直置中對齊。
    - **空白狀態引導**: 當字典分頁內容為空時，顯示置中提示「(目前的字典分頁是空的)」。
- **即時主題同步**: 實作主視窗與建議詞視窗的主題/字體大小即時同步機制，切換主題時不需重新開啟視窗即可同步變更。
- **視窗閃爍消除**: 優化 `ViewportBuilder` 的尺寸與位置設定時機，解決視窗啟動時的放大縮小跳動感。
