# UI 規格 (Tauri 原生)

## 主要區塊

- **頂部控制列**：選檔、選資料夾、輸出路徑、介面語言切換、導航按鈕。
- **設定面板 (Collapsible)**：服務商、模型、批次量、字體、語言、pack_format。
- **進度區**：條目進度、檔案進度、批次與目前路徑。
- **動作區**：開始、暫停、繼續、停止。
- **日誌區**：即時日誌顯示。
- **字典管理器**：原生 HTML `<dialog>` 疊層，不再佔用獨立視窗。

## 啟動預設狀態

- 目前狀態：`待機中`
- 已選檔案：空
- 輸出路徑：`./LLMTranslator` (UI 顯示預設路徑)
- API 設定面板：關閉
- 開發者模式：關閉
- 調色盤面板：關閉
- 字典管理器：關閉

## 設定面板預設值

- **服務商**：`無`
- **模型**：空值
- **API Key**：使用系統憑證鏈 (Keyring) 保護，免明文儲存。
- **Ollama URL**：`http://localhost:11434`
- **批次量**：`150` (範圍 1-300)
- **批次字數上限**：`3500` (範圍 1-10000)
- **逾時秒數**：`60` (範圍 1-600)
- **字體大小**：`15.0` (範圍 12-30)
- **來源語言**：`en_us`
- **目標語言**：`zh_tw`
- **介面語言**：`zh_tw` (動態載入)
- **資源包版本**：`15` (可用常用版本下拉)

**資源包常用版本選單**
- `1.21.4` → `46`
- `1.21.2` → `42`
- `1.16.5` → `6`

## 動作與控制預設值

- 暫停/停止：預設不可點擊 (需在翻譯中)。
- 開始翻譯：需要已選檔案且已有模型。

## 開發者模式預設值

- 跳過 JSON / JS / JAR / 手冊：預設皆為關閉。
- 記錄 LLM 通訊：預設關閉。

## 視窗幾何

- **主視窗位置**：起始自適應螢幕置中，隨後依使用者移動位置自動記錄，並在視窗 `CloseRequested` 時寫入 config。
- **字典管理器**：使用 HTML `<dialog>` 在主視窗中疊層顯示。

## 視覺與樣式預設值

- **主題**：`dark`
- **按鈕圓角**：啟用，數值 `4.0`

**深色調色盤 (預設)**
- 背景：`[30, 30, 35]`
- 文字：`[200, 160, 100]`
- 按鈕背景：`[45, 45, 50]`
- 按鈕文字：`[220, 220, 220]`
