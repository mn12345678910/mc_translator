## 3. 開發人員模式 (Developer Mode)
此面板由快捷鍵 `🔧` 開啟，提供細粒度掃描控制與日誌偵錯功能。

| 元件名稱 | 功能描述 | 即時存檔 |
| :--- | :--- | :--- |
| **跳過 .json** | 切換是否忽略專案中的 JSON 語系檔案 | 是 |
| **跳過 .js** | 切換是否忽略 JavaScript 腳本檔案 | 是 |
| **跳過 .jar** | 切換是否掃描 JAR 壓縮檔內部的資產 | 是 |
| **跳過手冊 (Books)** | 切換是否忽略 Patchouli 模組相關手冊檔案 | 是 |
| **開啟記錄日誌** | 切換背景執行緒的詳細 LLM 通訊記錄 | 是 |

## 4. UI 穩定性與規範

- **路徑分隔符**: 統一強制轉換為 `/` (Unix Style)。
- **路徑提取**: 僅顯示關鍵資訊 (如 `modid/en_us.json`)。
- **Viewport 閃爍修復**: 實作 `opened_last_frame` 延遲渲染，防止視窗跳位。
- **建議詞管理器**: 表格欄位原文與翻譯強制與背景帶狀條紋對齊。
- **日誌區域**: 使用 monospace 字體，過濾瑣碎掃描輸出。採用語義化標色（淺色主題成功：深綠 / 深色主題成功：綠 / 錯誤：紅 / 標籤色：一般）。
- **數值輸入範圍提示**: 所有 `DragValue` 後方須附帶 `(min-max)` 標籤輔助說明範圍。
- **資源包版本**: 提供預設常用 Minecraft 版本下拉選單，快速填入 `pack_format`。
- **國際化 (i18n)**: 全組件標籤、提示與日誌訊息均透過 `I18nLabels` 集中管理，嚴格禁止在 UI 元件中直接編寫硬編碼中文。支援 `source_lang` 與 `target_lang` 動態切換顯示邏輯。
