# UI 規格

> [!WARNING]
> **架構重塑中**：目前 GUI 正從 `egui` 遷移至 `Tauri`。本篇紀錄之預設值與調色盤 RGBA 陣列為 `egui` 歷史規格，在 Tauri HTML 選色及數值綁定中尚待完全對齊，僅提供參考。

## 主要區塊

- 頂部控制列：選檔、選資料夾、輸出路徑、介面語言切換、導航按鈕
- 設定面板：服務商、模型、批次、字體、語言、pack_format
- 進度區：條目進度、檔案進度、批次與目前路徑
- 動作區：開始、暫停、繼續、停止
- 日誌區：即時日誌顯示
- 字典管理器：獨立 Viewport

## 啟動預設狀態

- 目前狀態：`待機中`
- 已選檔案：空
- 輸出路徑：`./LLMTranslator` (UI 顯示預設路徑)
- API 設定面板：關閉
- 開發者模式：關閉
- 調色盤面板：關閉
- 字典管理器：關閉

## 設定面板預設值

- 服務商：`無`
- 模型：空值
- API Key：空值
- Ollama URL：`http://localhost:11434`
- 批次量：`150` (範圍 1-300)
- 批次字數上限：`3500` (範圍 1-10000)
- 逾時秒數：`60` (範圍 1-600)
- 字體大小：`15.0` (範圍 12-30)
- 來源語言：`en_us`
- 目標語言：`zh_tw`
- 介面語言：`zh_tw` (動態讀取 `./langs/*.json`)
- 資源包版本：`15` (可用常用版本下拉)
- 使用者翻譯提示：`DEFAULT_PROMPT` (內建預設)
- 系統技術指令：內建預設 (佔位符保護規則)

**資源包常用版本選單**
- `1.21.4` → `46`
- `1.21.2` → `42`
- `1.21` → `34`
- `1.20.4` → `22`
- `1.20.2` → `18`
- `1.20.1` → `15`
- `1.19.4` → `13`

- `1.18.2` → `9`
- `1.16.5` → `6`

## 動作與控制預設值

- 自訂 FPS：關閉
- 自訂 FPS 數值：`60`
- 暫停/停止：預設不可用 (需在翻譯中)
- 開始翻譯：需要已選檔案且已選模型 (或 `Google Free`)

## 開發者模式預設值

- 跳過 JSON：關閉
- 跳過 JS：關閉
- 跳過 JAR：關閉
- 跳過手冊 (Patchouli)：關閉
- 記錄 LLM 通訊：關閉

## 視窗幾何預設值

- 主視窗位置：`(50, 50)` (若為此預設值，初次啟動將自動計算螢幕置中，隨後依使用者移動位置自動記錄)
- 主視窗尺寸：`800 x 600`
- 字典管理器位置：`(100, 100)`
- 字典管理器尺寸：`800 x 600`

- 主題：`dark`
- 進度條呼吸動畫：啟用
- 呼吸動畫速度：`1.0`

## 狀態鎖定規則

- 翻譯中且未暫停時，設定面板多數欄位會鎖定
- 暫停時會解除鎖定，可修改大多數設定
- 主題、調色盤、字典管理器不受處理狀態影響

## Viewport 同步

- 字典管理器視窗會同步主視窗的主題、字體大小與調色盤快照
